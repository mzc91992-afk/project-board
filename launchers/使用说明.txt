项目看板 v1.0.0 · 下载即用
====================================

最简单：直接双击「项目看板.html」。
不用安装、不用账号、不用密钥、不用联网、不用建数据库。
所有功能（四种视图、时间线、批注、Excel / Markdown 导出）都能用，
数据只保存在这台电脑的浏览器里，刷新不丢。

想要独立窗口（没有浏览器地址栏）：
  macOS   双击 macOS/项目看板.app
          首次若提示「无法验证开发者」：右键点图标 → 打开 → 再点「打开」；
          或在终端执行 xattr -dr com.apple.quarantine <解压目录>
  Windows 双击 Windows/启动项目看板.bat（或 静默启动.vbs 不弹黑框）
  Linux   终端运行 bash Linux/启动项目看板.sh
启动器会优先调用 Chrome / Edge 的「应用模式」，没装则退回默认浏览器。

在线版（连下载都不用）：
  https://mzc91992-afk.github.io/project-board/

地址栏参数：
  ?demo=1      强制演示模式
  ?reset=demo  清空本机数据，恢复初始示例
  ?live=1      强制走云端（需自行配置）

注意：演示模式里的数据只在这台浏览器，不会同步到其它设备，也不上传任何服务器。
